Qobo1live Backend API Documentation
Base URL: https://my-backend-api-960q.onrender.com Last Updated: 28-Apr-2026
Standard Response Format
Every API response follows this structure:
{
"statusCode": 1,
"message": "Description of the result",
"data": {}
}
Field
Type
Description
statusCode
number
1 = Success, 0 = Failure
message
string
Human-readable result message
data
object | array | null
Response payload (null on errors)
Error Response Example
{
"statusCode": 0,
"message": "Not authorized, no token",
"data": null
}
Authentication Header
All endpoints marked 🔒 require a JWT Bearer token:
Authorization: Bearer <jwt_token>
